# Autonomous Driving Lane Detection

## Overview

This project detects road lane markings from dashcam videos using OpenCV and Python.

## Technologies Used

- Python
- OpenCV
- NumPy

## Features

- Edge Detection using Canny
- Region of Interest Selection
- Lane Detection using Hough Transform
- Real-time Video Processing

## Project Structure

Lane_Detection_Project
│
├── lane_detection.py
├── requirements.txt
├── README.md
└── screenshots

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python lane_detection.py
```
